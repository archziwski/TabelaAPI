# Güvenlik

Güvenlik açıklarını public issue olarak paylaşmadan önce proje yöneticilerine özel olarak bildirin.

Özellikle şu alanları raporlarken kanıt ve etki kapsamı ekleyin:

- Oyuncu girdisinin başka bir oyuncuya taşınması.
- Velocity bridge kimlik doğrulama atlatmaları.
- Yetki kontrolü atlatmaları.
- Packet veya regex kaynaklı kaynak tüketimi.
- Hassas verinin debug loglarına yazılması.
